================================================================================

COMO USAR:

1. PRIMEIRO: Instale Python (se não tiver)
   - Acesse: https://www.python.org/downloads/
   - Baixe Python 3.8 ou superior
   - IMPORTANTE: Marque "Add Python to PATH" durante a instalação
   - Clique em "Install Now"

2. DEPOIS: Duplo clique em "VisualizadorBancoDados.bat"
   - O script instalará as dependências automaticamente
   - Abrirá a aplicação em http://localhost:5003/

3. PRONTO! Use a aplicação

================================================================================
TROUBLESHOOTING:
================================================================================

PROBLEMA: "Python não está instalado"
SOLUÇÃO: Instale Python de https://www.python.org/downloads/

PROBLEMA: "Porta 5003 já está em uso"
SOLUÇÃO: Aguarde 30 segundos ou reinicie seu computador

PROBLEMA: Navegador não abre
SOLUÇÃO: Abra manualmente em http://localhost:5003/

PROBLEMA: Erro ao instalar dependências
SOLUÇÃO: Abra Command Prompt como administrador e execute:
  pip install flask flask-cors openpyxl requests
